Política de privacidad

Esta aplicación la usa únicamente su propietario con su propia cuenta. No tiene otros usuarios, no recopila datos de terceros, y no vende ni comparte información con nadie ni la usa para publicidad.

El uso de datos obtenidos de las APIs de Google cumple la Google API Services User Data Policy, incluidos los requisitos de uso limitado.
